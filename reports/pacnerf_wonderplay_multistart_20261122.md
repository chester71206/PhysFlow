# PAC-NeRF WonderPlay multistart run

Launched 2026-11-22 on physical GPUs 1–7, one trainer per GPU. GPU 0 is running the separate synthetic 10×/100× study; GPUs 8–9 belong to another user. The 27 PAC-NeRF jobs cover all nine dataset scenes and three starts each, with 50 optimizer updates requested per job. The scheduler runs GT starts first, then near starts, then distant starts as GPUs free up.

Run or resume with:

```bash
/disk2/ccchen/miniconda3/envs/physflow/bin/python -u scripts/run_pacnerf_wonderplay_multistart.py --gpus 1,2,3,4,5,6,7 --epochs 50 --timeout 10800
python scripts/report_pacnerf_wonderplay_multistart.py
```

The queue state is `runner_state.json`. Each job has `physics_config.json`, `segment_XX.log`, `segment_XX/training.jsonl`, an initial gradient report, and a per-update `segment_XX/ckpt/optimizer.pt`. Timed-out jobs resume into a new segment, preserving every prior segment. A failed gradient gate or numerical failure is recorded as failed and is not treated as convergence.

The GT anchors come from `outputs/pacnerf_wonderplay_diagnostics_20261113/gt_injection/*/checkpoint.json`, which stores solver-native conversions of the dataset parameters. For cream and toothpaste, the plastic-viscosity anchor is the solver's fixed 0.0001 value; its conversion to a physical GT has not been validated. GT here means a physical parameter anchor, **not** a zero WonderPlay loss: the observed flow and model may disagree even at GT.

Near starts use E×1.25, a small ν perturbation, and ×1.25 for active yield/viscosity parameters. Far starts isolate E×10 while holding other parameters at the anchor. Sand has no active E parameter: trophy starts at 40°, 45°, and 70° friction angle. High-E far starts may be outside the stable range of the fixed MPM timestep; report those as numerical validity failures. For the elastic/Newtonian trainer, E is clamped after updates to 10⁻⁷–10⁻⁰·⁴, so an initial far E outside this range is flagged in the final analysis.

`summary.csv` and `summary.json` are snapshots generated by the report script. `near_GT` means all active parameters are within 10% relative error (ν within 0.01 absolute, friction angle within 5°). It is not by itself proof of local convergence; inspect loss and gradients before calling an away-from-GT run a local minimum. The Gaussian self-consistent synthetic test and the observed PAC-NeRF WonderPlay loss are separate experiments.
